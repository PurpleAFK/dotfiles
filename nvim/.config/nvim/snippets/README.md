# Key snippets included:

## Templates:

- cptemplate - Basic template
- cpt - Template with testcases (for Codeforces Div 2/3)
- cpdebug - Template with debug macros
- cpgraph - Graph problems template
- cpdp - DP problems template

## Algorithms:

- bfs - BFS traversal
- dijkstra - Dijkstra's algorithm
- binsearch - Binary search
- segtree - Segment tree (for CSES range queries)
- dsu - Union-Find (for connectivity problems)

## Data Structures:

- vec, vec2d - Vectors
- map, set - STL containers
- pqmax, pqmin - Priority queues

## Utilities:

- reada, printa - Read/print arrays
- mod - Modular arithmetic (for large number problems)
- fori, forr, fore - Different loop types

Most CSES problems use cptemplate, while Codeforces usually needs cpt (multiple testcases).
Just type the prefix and hit Tab!
